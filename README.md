# AjayXGlory — غرفة التحكم بمجد الجيلد

بوت رفع مجد الجيلد (Guild Glory) للعبة Free Fire مع لوحة تحكم ويب عربية بالكامل وبوت تلجرام للمراقبة.

## المميزات
- لوحة تحكم عربية RTL تعرض: مجد الجيلد المباشر، الأعضاء، الفرق (السكوادات)، السجل المباشر.
- إنشاء حسابات جديدة تلقائياً وإرسالها للانضمام إلى الجيلد ثم بدء رفع المجد.
- إعادة تسجيل دخول تلقائية عند انتهاء التوكن، وأرشفة الحسابات القديمة مع إمكانية إعادة تفعيلها.
- بوت تلجرام للمراقبة: `/status` `/glory` `/log`.

## التشغيل المحلي
```bash
pip install -r requirements.txt
python app.py
```
ثم افتح المتصفح على `http://localhost:7777`.

> لتفعيل بوت تلجرام محلياً: ضع التوكن في ملف `telegram_token.txt` بجانب المشروع (موجود مسبقاً) أو في متغير البيئة `TELEGRAM_BOT_TOKEN`.

## متغيرات البيئة
| المتغير | الوصف |
| --- | --- |
| `PORT` | المنفذ (يضبطه Railway تلقائياً — الافتراضي محلياً 7777) |
| `TELEGRAM_BOT_TOKEN` | توكن بوت تلجرام (اختياري) |
| `TELEGRAM_CHAT_ID` | معرف محادثة تلجرام للتنبيهات (اختياري — يتعلمه البوت تلقائياً من أول رسالة ترسلها له) |

## النشر على Railway
1. ارفع المشروع إلى مستودع GitHub (تم التجهيز: `Procfile` + `requirements.txt`).
2. في Railway: **New Project → Deploy from GitHub repo** واختر المستودع.
3. أضف متغير البيئة `TELEGRAM_BOT_TOKEN` (وقيمته توكن بوت تلجرام) من تبويب **Variables**.
4. Railway سيتعرف على المنفذ تلقائياً عبر `PORT` وسيولد رابطاً عاماً للوحة التحكم.

## ملاحظات
- ملفات البيانات (`accounts.json`، `token_cache.json`...) تُنشأ تلقائياً عند التشغيل ولا ترفع إلى المستودع.
- عدّل إعدادات الفريق والفواصل من أعلى ملف `app.py` (قسم CONFIG).
